# Affy’s AI Ordering System

Affy’s AI Ordering System is a web app designed to improve how customers place food orders from Affy’s.

The goal is to replace repetitive manual order conversations with a structured digital ordering experience that includes:
- a redesigned website
- an AI-guided ordering assistant
- a quick order form
- structured order capture
- payment handoff
- reusable customer and order data

## Project status
Planning and architecture phase.

## Planned stack
- Frontend: Next.js + Typscript
- Backend: Next.js Route Handlers + Server Actions (V1)
- Database: Supabase
- Payments: Stripe
- AI: OpenAI API
